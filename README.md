# Yujin Jeong — Quarto Portfolio Website

This project contains the files for the M10 Hands-on Practice assignment.

## Files

- `index.qmd`: Home page with bio, career aspirations, skills, education, and experience
- `dashboard.qmd`: Avenue Shabu Quarto dashboard portal
- `css.qmd`: CSS/SCSS explanation and examples
- `listings.qmd`: Explanation of Quarto Listings and future portfolio use
- `_quarto.yml`: Website navigation and project configuration
- `styles.css`: Custom visual styling
- `assets/profile-placeholder.svg`: Temporary profile image

## Before publishing

1. Replace `assets/profile-placeholder.svg` with a professional photo, keeping the filename `profile-placeholder.svg`, or update the image path in `index.qmd`.
2. Replace every occurrence of `YOUR-USERNAME/YOUR-REPOSITORY` in `_quarto.yml` and `index.qmd`.
3. Render the site with `quarto preview` and check every page.
4. Publish using GitHub Pages with `quarto publish gh-pages` or publish the `_site` folder through Netlify.
